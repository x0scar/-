# Интерактивная карта
The Continent — это веб-приложение, представляющее собой интерактивную карту фэнтезийного мира «Ведьмака» от Анджея Сапковского. Приложение позволяет исследовать континент, добавлять собственные локации с описаниями (лором), систематизировать их по типам и уровням опасности, а также делиться картой с другими пользователями.
